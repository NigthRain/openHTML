核心模块 · 01–05

五个协同工作的
功能模块

模块 01
🖥
Web UI 门户
Astro · Tailwind CSS
对外暴露的用户交互层，提供极简的拖拽/拍照上传界面，通过 WebSocket/SSE 实时渲染后端推送的鉴定进度。
拖拽/拍照上传，实时进度推送
EXIF 缺失时自动弹出手动补录选择器
渲染"三位一体"鉴定证据链报告
模块 02
⚙
工作流调度与聚合
Python · FastAPI · Redis RQ
系统核心调度中枢，承担任务排队、EXIF 特征剥离、代理轮询三项职能，驱动所有下游子任务并发运行。
Redis + RQ 持久化队列，进程重启不丢任务
OSM 优先 + 本地离线双轨降级逆地理编码
ZeroTier 代理池健康检查与自动切换
模块 03
🔭
多源感知探针
纯 API 模式 · 无爬虫
并发向四类识别数据源发起请求，每个探针独立设置 10 秒熔断超时，单源失败不影响整体流程。
海外组：PlantNet API、iNaturalist API
国内组：百度智能云、阿里云/腾讯云
多模态组：Gemini Vision、Qwen-VL
模块 04
🗄
权威数据库验证
httpx · BeautifulSoup4 · SQLite
以最终裁决学名为键，查询本地缓存或按需抓取权威植物数据库，实现"查过一次，终生本地化"。
优先 GBIF API（开放 RESTful）
辅助 iPlant.cn / PPBC 定向抓取
Redis 热缓存 + SQLite 冷持久化双层存储
模块 05
◈
大模型裁决引擎
Gemini Pro · 结构化 JSON 输出
系统质量的核心环节。接收多源杂乱结论与时空上下文，通过专家委员会式 Prompt 推导唯一共识学名。
翻译拉丁文，指出多源分歧并分析成因
结合地理生境排除不可能的物种
输出 high / medium / low 三级置信度
特征剥离 · 附属功能
📍
EXIF 时空特征提取
exifread · reverse_geocoder
将原始 GPS 坐标与时间戳降维为大模型可理解的自然语言上下文，显著提升排除误判的准确率。
月份 → 季节（春/夏/秋/冬）
海拔数值 → 低/中/高海拔定性描述
省级行政区 → 中国大区（西南/华南等）

从上传到证据链
的完整路径

步骤 2 与步骤 3 并行执行，EXIF 提取与多源识别同时进行，最大化利用等待窗口，整体响应时间控制在 15–30 秒内。

📤
步骤 01
用户提交

⌖
步骤 02
特征剥离
提取 EXIF 经纬度、海拔、拍摄时间，降维为季节 + 大区 + 海拔描述

⊹
步骤 03
多源并发识别
四路 API 并发请求，10 秒熔断超时，各源陆续返回初步结论与置信度

◈

大模型裁决
多源结论 JSON + 时空上下文 → 大模型排除矛盾项 → 输出唯一共识学名
📖
步骤 05

以学名为键查本地缓存；未命中则抓取 iPlant / GBIF 并永久写入
✦

裁决机制 · 置信度分级

三级置信度
触发不同系统行为

High · 高置信度
多源结论一致，时空上下文与识别结果无地理矛盾，大模型直接得出唯一共识学名。
直接推进权威数据库对照，组装完整证据链返回用户。
Medium · 中等置信度
各来源之间存在种级分歧，但大模型可结合地理生境合理排除其中的候选项。
推进权威对照，前端报告附加分歧说明与区分要点提示。
Low · 低置信度
分歧严重，候选项在地理与形态上均难以区分，大模型无法确定唯一结论。
返回候选列表，提示用户补充叶片/花部特写，说明当前结果仅供参考。

权威数据源策略

缓存键结构设计
Redis 热缓存 + SQLite 冷持久化
latin_name 拉丁学名（主键）
cn_name 中文名
family / genus 科名 / 属名
morphology 权威形态描述文本
distribution 地理分布区域描述
ref_image_url 权威对照图 URL
source / cached_at 数据来源 + 入库时间戳
📡
权威数据源优先级
合规优先，稳定 API 优于爬虫
数据源访问方式优先级
GBIF API 开放 API P0 首选
Wikipedia / Wikidata 开放 API P1 补充
iPlant.cn 定向抓取 P2 辅助
PPBC 植物图库 定向抓取 P2 辅助
Flora of China 定向抓取 P3 备选
部署前须核查抓取目标的 robots.txt 及服务条款。存在限制时优先切换至开放 API 数据源。
